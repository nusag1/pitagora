# ピタゴラ工房

板・ドミノ・バネ・重い玉を置いて、玉をゴール（コップ／ベル）まで運ぶ装置を作る物理パズル。Matter.js 0.19（cdnjs）。

- `core.js`：ステージ・部品・物理の世界・クリア判定・置けるかの判定（画面なしでも動く。テストは bun で）
- `index.html`：画面（置く・ドラッグで動かす・回す・しまう、スタート、星、見本、効果音）
- ステージ6つ＋じゆうに作る。どのステージも「何も置かないとクリアできない」「見本の置き方でクリアできる」ことを確認済み（見本はランダムに置いて探し、いらない部品を減らしたもの）
- バネはさわったものを、バネの向きに速さ15ではね返す
- 記録（星・置いた部品）は見る人のブラウザ（localStorage）
